SICM — DEMOSTRACIÓN AUTOMÁTICA

1. Abra index.html con Google Chrome o Microsoft Edge.
2. Pulse “Iniciar demostración con narración”.
3. Permita el audio y use “Pantalla completa” para una experiencia profesional.
4. La voz proviene del motor de narración en español instalado en el navegador.

Controles: pausar/continuar, activar/silenciar y pantalla completa.
Duración: 5 minutos (20 escenas de 15 segundos).

Para obtener un MP4, reproduzca la demo en pantalla completa y grábela con OBS Studio,
incluyendo el audio del sistema.
